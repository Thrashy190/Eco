# Eco for Roku

The TV app: browse your library with the remote, or send music to the TV from Eco on your phone. Plain BrightScript and
SceneGraph, installed on a Roku in developer mode (no store involved).

- How to install and use it: [docs/tv.md](../docs/tv.md)
- How it is built and tested: [docs/tv.md, For developers](../docs/tv.md#for-developers)

```
source/        main.brs (starts the app) and screensaver.brs
components/    MainScene (navigation, Player.brs, Connect.brs, Theme.brs), screens/, widgets/, tasks/ (network), lib/
tests/         the pure logic, run in the brs-node interpreter (npm test)
tools/         make-images.py, make-fonts.py, install.sh
images/, fonts/  generated by tools/; Bricolage Grotesque under the SIL Open Font License (fonts/OFL.txt)
```
